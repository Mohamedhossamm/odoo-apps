POS Order Status Screen with Voice Calling

Show Preparing and Ready order numbers on a TV, and call each ready order out loud in Arabic and English. Works straight from the Point of Sale: no kitchen display needed.

شاشة تعرض أرقام الطلبات قيد التحضير والجاهزة، وتنادي على كل طلب جاهز بالصوت بالعربي والإنجليزي. تعمل من نقطة البيع مباشرة بدون شاشة مطبخ.

How it works

1. The customer pays

Every paid order appears under Preparing with its order number, automatically.

2. The cashier taps "Ready"

A new button in the POS top bar opens the order list. One tap moves an order to Ready.

3. The screen calls it out

The TV plays a chime and says "Order number 318 is ready", in Arabic, English or both.

Cashier panel

Mark orders ready, mark them collected, or send one back to preparing if it was tapped by mistake. Fully translated to Arabic.

Features

  • Voice calling in Arabic, English, or Arabic then English, repeated as many times as you choose. A chime plays before each call.
  • No kitchen display required. Ideal for cafés, bakeries, food trucks and take-away counters.
  • Live updates every 3 seconds, with no page reload. Newly ready numbers blink.
  • Any screen with a browser: TV, tablet or second monitor. Opens from a secret link, no login needed.
  • Secure link per point of sale. Create a new link at any time to disable the old one.
  • Ready orders clear themselves after the number of minutes you set, or stay until collected.
  • Several cashiers, one screen: statuses are stored on the server, so every register sees the same list.
  • Bilingual screen labels: قيد التحضير / Preparing, جاهز للاستلام / Ready.

Setup

  1. Install the app.
  2. Go to Point of Sale › Configuration › Settings › Order Status Screen, choose the voice language and repeat count.
  3. Open the Order Status Screen Link on the TV's browser, or from the POS with Open customer screen.
  4. Tap "Tap to enable sound" once on the TV. Browsers block sound until someone taps the page.

Voice requirements

The voice uses the text-to-speech engine built into the screen's browser, so it needs no internet service and no subscription. The browser must have an Arabic voice for Arabic calls; when it has none, the Arabic call is skipped and the chime still plays.

Tested on: Google Chrome on macOS.
