Search in One2many & Many2many Lists

A search bar like Odoo's search view, above every list inside a form: invoice lines, order lines, picking moves, BoM components...

Find a line in seconds

Type in the search bar above the lines and pick where to search, exactly like in Odoo's search view: all columns, or one column such as Product, Label or Quantity.

Combine filters

Each choice becomes a facet. Two values in the same column match either one (desk or chair); facets on different columns must all match. The bar shows how many lines match, for example 4 / 45. Remove a facet with its × or with Backspace.

Features

  • Works on every one2many and many2many list in every form, in every app, with no configuration.
  • Searches all the lines, not only the current page: a 300-line order is searched in full.
  • Searches what the list shows: product and partner names, selections, dates, numbers as stored or as displayed (2 or 2.00).
  • Lines you are adding or editing stay visible while a search is active, and saving is not affected.
  • Arabic-aware: أحمد = احمد = إحمد, قهوة = قهوه, مستشفى = مستشفي, tashkeel ignored, Arabic digits ٠١٢ = 012.
  • Looks native in every theme: it uses the same markup as Odoo's search view.
  • Hide it on one field with options="{'no_search': True}".

Compatibility

  • Odoo 19, tested on Community edition.
  • Depends only on the web client (web).
