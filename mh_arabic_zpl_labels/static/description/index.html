Arabic Product Labels for Zebra (ZPL)

Arabic product names that print joined and right-to-left on thermal label printers.

Zebra and other ZPL printers cannot join Arabic letters: text sent to them comes out empty or broken. This module sends the Arabic text as a sharp graphic, so every printer prints it exactly as it looks in Odoo.

Correct Arabic, any printer

Joined letters, right-to-left, Arabic and English in the same name. No font to download to the printer, works on old models too.

Name, price, barcode

Long names wrap on two lines and shrink to fit. Price with your own text and currency. EAN-13 or Code 128 barcode, centered.

ZPL or PDF

A .zpl file for Zebra, Xprinter, TSC and other ZPL printers at 203 or 300 dpi, or a PDF with one label per page for any printer.

Real labels made by the module

50 x 25 mm at 203 dpi, rendered from the module's ZPL output.

Print from the products list

How it works

  1. Select products in Inventory, Sales or Purchase product lists (or open one product).
  2. Click Actions > Print Arabic Labels.
  3. Pick the label size, the printer resolution and what to show: price, internal reference, barcode. Set how many labels you need of each product.
  4. Click Print and send the downloaded .zpl file to your printer, or print the PDF.

Good to know

  • Sizes included: 50x25, 40x30, 38x25, 58x40, 100x50 mm, or any custom size.
  • Uses the Tajawal font that comes with Odoo. Nothing to install on the server or the printer.
  • The price text is yours to set, for example السعر: or Price:, and the currency text too.
  • Text is printed as a graphic, so the ZPL file is larger than plain text labels. Printers handle it in under a second per label.
